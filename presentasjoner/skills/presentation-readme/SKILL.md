# README per presentasjon

Hver presentasjonsmappe skal ha en `README.md` ved siden av `.pptx`-filen. Start fra `maler/README-mal.md`.

## Retningslinjer

1. Opprett README samtidig som mappen. Ikke vent til presentasjonen er ferdig.
2. Hold den i synk: oppdater tidsplan, kilder og åpne punkter hver gang slides endres.
3. Seksjoner (alle skal med, hopp over bare hvis de ikke gjelder):
   - Fakta: arrangement, dato, varighet, målgruppe, filnavn, status
   - Budskap
   - Tidsplan slide for slide, og summen må stemme med varigheten
   - Kilder og påstander, med status verifisert / ikke verifisert / egen vurdering
   - Bildekreditering og lisenser (opphavsperson, lisens, URL)
   - Lenker (live-demo, videoer)
   - Åpne punkter som avkrysningsliste
   - Notater i selve pptx-filen følger `presentation-notes`; README er den leservennlige versjonen
4. Aldri skriv en påstand som verifisert uten at kilden er åpnet og lest.
5. Skriv på norsk bokmål, kort og skannbart. Bruk tabeller for tidsplan og kilder.
6. Ikke legg hemmeligheter eller interne dokumenter i README (repoet er privat, men hold det rent).
7. Bildekreditering som krever attribusjon (f.eks. CC BY-SA) skal også stå på selve sliden.
